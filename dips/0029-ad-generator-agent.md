# DIP 0029: `ad-generator-agent`

## What

A buyer-side agent that turns one landing-page URL into a complete ad set and
does the generative work on c0mpute instead of a paid AI API. First consumer:
crawlproof.com `/dashboard/ads/new`, where it is **on by default**
(`AD_GENERATOR_AGENT=off` restores the previous providers).

It ships no worker code. Every step buys a workload that already exists, so
workers earn from it by serving those workloads.

## Ad types and where each one is made

| Ad type (crawlproof format / media kind) | Generated by | Route |
|---|---|---|
| Copy for every format: Medium Rectangle, Leaderboard, Mobile Banner, Text Link, Terminal (ASCII), Feed item, the 5 s pre-roll's lines, and the short/long product summaries | `infernet.inference` | Infernet `POST /api/chat`, trusted client key, `p2p_only` (never Infernet's hosted fallback) |
| Narration: the pre-roll's voice track and the `audio` companion | `tts.synthesize` | `c0mpute speech serve` gateway `POST /v1/tts`, Kokoro `af_sarah` |
| `static` (HTML banner) | deterministic render of the copy + brand palette | buyer app, no model |
| `image` (hero artwork behind the banner) | advertiser's own `og:image`; `diffusion.txt2img` when diffusion workers exist | diffusion is a candidate plugin with **no live workers yet** |
| `gif` | frames of the static design, encoded with ffmpeg | buyer's own render worker (no paid service) |
| `video` (5 s pre-roll) | frames + narration muxed with ffmpeg | buyer's own render worker; `ffmpeg.transcode` once creative uploads go through the storage plugin |
| `audio` | the narration, re-encoded | buyer's own render worker |

## Fallbacks

* **Copy:** c0mpute first. The fleet-wide `@profullstack/ai-providers` router
  may fall back to OpenAI/Anthropic, alternating, when c0mpute fails (standing
  rule since 2026-11-02); the agent does not add any other paid route.
* **Narration:** c0mpute only while the agent is on. A failed synthesis is a
  retryable render error; the job retries rather than publishing a silent ad or
  calling a paid TTS API.
* **Artwork:** no paid image generation while the agent is on unless the
  operator sets `AD_GENERATOR_PAID_IMAGES=1`. Without an `og:image` the ad ships
  with its accent-tinted background, which every format already supports.

## What is missing for artwork on c0mpute

`diffusion.txt2img` (plugins/diffusion) has a manifest and no runner. To make it
live it needs: a runner (stable-diffusion.cpp or ComfyUI) with a pinned model,
a role or capability tag workers advertise, a result path for ~0.5 MB PNGs
(gossip results are capped far below that; TTS already returns WAV bytes over
the speech gateway's store path, which is the model to copy), and at least one
GPU (or slow CPU) worker serving it. When it ships, the agent adds it between
`og:image` and "no artwork".

## Configuration (buyer side)

| Name | Meaning |
|---|---|
| `AD_GENERATOR_AGENT` | `off`/`0`/`false` disables the agent (default on) |
| `C0MPUTE_API_KEY`, `C0MPUTE_URL` | Infernet trusted client key and base URL for copy |
| `C0MPUTE_SPEECH_URL`, `C0MPUTE_SPEECH_TOKEN` | speech gateway for narration |
| `AD_GENERATOR_TTS_ENGINE`, `AD_GENERATOR_TTS_VOICE` | default `kokoro` / `af_sarah` |
| `AD_GENERATOR_PAID_IMAGES` | `1` allows gpt-image heroes while the agent is on |
